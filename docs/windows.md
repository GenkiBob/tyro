# Windows 电脑教程

若设备中已有**同类软件**或**旧版APP**，请先 **断开连接** 并 **卸载** ，避免出现异常情况导致无法正常使用。

## 01 下载地址

[点击下载](https://154.26.185.131:50089/d/home/alist_files/client/c/alt/digilink.exe)

:::tip
安装问题处理：

1. 若浏览器提示无法下载，请按照下方 《02 安装》 步骤操作

2. 若首次打开软件出现报错，请尝试以管理员身份运行客户端：在桌面找到 Digilink 图标，鼠标右键选择以管理员身份运行

3. 若仍然提示错误，请先完全退出软件，并卸载电脑中的同类软件或旧版 APP，重启电脑后重新安装

完全退出软件方法：

在屏幕右下角软件托盘处，找到 Digilink 图标，鼠标右键选择退出。
:::

:::tip
使用问题：

1. 若 连接 后无法正常使用，请在屏幕右下角软件托盘处找到 Digilink 图标，鼠标右键勾选 TUN，并重新勾选系统代理。

2. 退出软件或关机前，请先 断开 连接，或打开 开机自启，避免影响下次上网。
:::

**若以上APP无法安装或使用，请 卸载后 再下载备用 APP**
